    অথবা choose your files ক্লিক করে সব বেছে নিন

cd news-portal git init git add . git commit -m "first upload" git branch -M main git remote add origin https://github.com/আপনার-ইউজারনেম/news-portal.git git push -u origin main

  • Add variable ক্লিক করুন

  1. render.com → Get Started → GitHub দিয়ে সাইন আপ করুন (সবচেয়ে সহজ)
  2. GitHub কানেক্ট করলে Render আপনার সব রিপো দেখতে পাবে → news-portal সিলেক্ট করুন

ধাপ ২ — সার্ভিস তৈরি

  1. ড্যাশবোর্ডে New + → Static Site ক্লিক করুন ⚠️ (Web Service নয়!)
  2. news-portal রিপো সিলেক্ট করুন → Connect
  3. নিচের মতো পূরণ করুন:
Name → news-portal Branch → main Build Command → খালি রাখুন Publish Directory → . (শুধু একটা ডট)
💡 আপনার জন্য render.yaml ফাইল আগেই বানানো আছে — ZIP-এর রুটে। সেটা থাকলে Render নিজে থেকে সব সেটিং চিনে নেবে, আপনাকে কিছুই লিখতে হবে না।
  1. Create Static Site ক্লিক করুন
  2. ১-২ মিনিট অপেক্ষা করুন → ড্যাশবোর্ডে "Live" সবুজ ব্যাজ

ধাপ ৩ — আপনার ফ্রি ডোমেইন পাবেন

https://news-portal.onrender.com

এই লিংকটি উপরে বামদিকে দেখাবে। কপি করে রাখুন।

ধাপ ৪ — SITE_URL আপডেট করুন (ভুললে sitemap ভুল হবে)

GitHub → Settings → Secrets and variables → Actions → Variables → SITE_URL → Edit → নতুন লিংক বসান → Save
https://news-portal.onrender.com

এরপর Actions → Update News → Run workflow — সাইটম্যাপ নতুন লিংক দিয়ে তৈরি হবে।

✅ Render কবে বেছে নেবেন

  • ✅ .onrender.com ডোমেইনটা .github.io/news-portal-এর চেয়ে ছোট ও সুন্দর
  • ✅ কোনো cold start নেই — সবসময় দ্রুত লোড
  • ✅ কাস্টম ডোমেইন ফ্রি যুক্ত করা যায় (Settings → Custom Domains)
  • ✅ GitHub Actions ক্রন ঠিক আগের মতোই কাজ করবে — news.json আপডেট → push → Render স্বয়ংক্রিয়ভাবে রিডিপ্লয়
  • ⚠️ একটাই সীমাবদ্ধতা: মাসে ৫০০ বিল্ড মিনিট। আমাদের সাইটের বিল্ড লাগে ~১০ সেকেন্ড, তাই দিনে ৪৮ বার ডিপ্লয় করলেও মাসে মাত্র ~৪ মিনিট খরচ। কোনো সমস্যা নেই।
🎯 আমার পরামর্শ: দুটোই একসাথে রাখতে পারেন — GitHub Pages (ব্যাকআপ/প্রাইমারি) + Render (সুন্দর ডোমেইন)। দুটোই ফ্রি, দুটোই GitHub Actions থেকে আপডেট হয়। কোনো ঝামেলা নেই।

সমস্যা হলে — সাধারণ সমাধান

❌ "Your site is live at" দেখাচ্ছে না / ৪০৪

→ ৫-১০ মিনিট অপেক্ষা করে রিফ্রেশ করুন। এরপরও না হয়: Actions ট্যাবে লাল চিহ্ন আছে কিনা দেখুন। সবুজ টিক থাকলে সব ঠিক আছে — শুধু সময় লাগছে।

❌ Actions-এ লাল ✗ / workflow failed

→ কারণ প্রায় সবসময় Workflow permissions। ধাপ ৫-এর (ক) অংশটি আবার করুন, তারপর Actions → সবুজ বাটন "Re-run all jobs" ক্লিক করুন।

❌ সাইট খুললে "Data load failed"

→ মানে data/news.json আপলোড হয়নি। রিপোতে data ফোল্ডার আছে কিনা চেক করুন। না থাকলে আবার আপলোড করুন।

❌ খবর আপডেট হচ্ছে না

→ Actions ট্যাবে গিয়ে দেখুন সর্বশেষ কবে চলেছে। GitHub মাঝে মাঝে ৬০ দিন নিষ্ক্রিয় থাকলে ক্রন বন্ধ করে দেয় — সমাধান: মাসে একবার Run workflow চাপুন।

❌ ছবি লোড হচ্ছে না

→ কিছু সংবাদপত্র (NDTV) বাইরে থেকে ছবি দেখাতে দেয় না। সাইট নিজেই সুন্দর গ্রেডিয়েন্ট প্লেসহোল্ডার দেখায় — ডিজাইন নষ্ট হয় না। এটা স্বাভাবিক।
